# Deep Research Skill

Conduct thorough, multi-source research and produce a cited report.

## Research Protocol
1. **Fan-out searches** — Search with 3-5 different query formulations
2. **Source collection** — web_fetch the most promising URLs from each search
3. **Cross-verify** — Check claims against multiple independent sources
4. **Synthesize** — Combine findings into a coherent narrative
5. **Cite** — Every factual claim must have a source URL

## Quality Gates
- Minimum 3 independent sources per major claim
- Prefer official docs, academic papers, reputable publications
- Flag conflicting information explicitly
- Distinguish between fact and opinion in the report

## Output Format
```
# Title
## Executive Summary (3-5 sentences)
## Key Findings (numbered, with citations)
## Detailed Analysis
## Conflicting Views (if any)
## Sources (numbered URL list)
```
