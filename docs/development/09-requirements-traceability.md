## 9. 未落地处理

如果开发中出现要求无法在对应阶段实现：

1. 不得删除本表条目；
2. 将功能注册表状态保持 `designed` 或 `implemented`；
3. 正式 UI 不显示为可用；
4. 记录阻塞原因、影响和新的目标阶段；
5. 若改变产品语义，先让用户审核文档。
