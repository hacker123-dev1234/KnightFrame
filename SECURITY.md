# Security Policy

Please report vulnerabilities privately to the project maintainers before publishing details. Include the affected version, reproduction steps and expected impact. Do not include live credentials or private project data.

KnightFrame stores provider secrets in Windows Credential Manager. Configuration and open-source exports must contain credential references only. Logs, diagnostics, fixtures and screenshots must be reviewed for secrets before sharing.

KnightFrame intentionally provides broad local agent access. Real trading, ordering, position changes and automated purchasing remain prohibited. Users should run untrusted plugins and projects only in an environment whose filesystem and credentials they are prepared to expose.
